# 公众号参考样式：楷体红 v1

参考来源：[金融风控建模之数据有效性分析](https://mp.weixin.qq.com/s/z-XzPniWyzlyhh8gJAqwjA)。2026-11-03 读取原文 DOM、内联样式和 390px 浏览器计算样式，并对照手机宽度截图。主题只复现排版语言，示例正文为新写内容，不复制原文或报告图片。

## 样式分析

| 元素       | 原文观察                                                                         | 本地实现                                                                |
| ---------- | -------------------------------------------------------------------------------- | ----------------------------------------------------------------------- |
| 主色       | 深红 `#c00000`，部分阴影为 `#ff0000`                                             | 固定深红章节、红色细线与强调段                                          |
| 正文       | 主要为楷体 / 楷体\_GB2312 / SimKai、14px、`#262626`                              | 14px 楷体优先字体栈，支持在完整样式设置中调整                           |
| 行距与缩进 | 常规正文主要为 22.4px 行高，段首 34px；个别段落使用 1.5px 字距                   | 正文行高 1.6、段首 34px，常规字距 0.544px；引言保留 1.5px 字距          |
| 引言       | 红色顶线、白底红字标签、浅粉底 `#fcf2f2`，内边距 10px                            | `WeChatIntroV1`；段落 14px、1.75 行高、28px 缩进                        |
| 二级章节   | 宽度约 50%，居中；25px 红色数字块、中文编号和带红影的细线                        | Markdown `##` 自动生成；首章从“零”开始，也支持显式编号                  |
| 三级章节   | 宽度约 35%，靠左；01/02 编号、较粗数字下划线和细标题下划线                       | Markdown `###` 自动生成，进入新章节后重新编号                           |
| 代码块     | Atom One Light；`#fafafa` 浅底、`#383a42` 文本、12px 等宽字；高亮 span 行高 26px | 本地 `atom-one-light` 配色，26px 代码行距、5px 圆角和同参数阴影         |
| Mac 标题栏 | 三个圆点，原文使用远程 SVG 背景                                                  | 用三个真实 span 和内联颜色绘制，不依赖远端图片                          |
| 报表与宽表 | 复杂图表以图片呈现；正文没有原生 HTML 表格                                       | `WeChatFigureV1` 插入作者自己的报告图片；另附浅粉表头的原生表格配套样式 |

原文存在少量混合字号、缩进和字距。本主题选择其主要参数作为可长期复用的规范，避免把历史编辑产生的偶然差异固化。网页上方由微信提供的文章标题、作者栏和底部互动栏由平台控制，不纳入正文主题。示例中的正文 h1、原生表格和引用为配套扩展。

## 使用

1. 打开编辑器顶部「成稿检查 → 主题与代码」。
2. 选择「公众号·楷体红」。
3. 点击「新建同款排版示例」新增示例文章，当前文章不会被替换。
4. 二、三级标题直接使用 Markdown；引言、红底短句、红色强调和报告图片可从「固定组件」插入。
5. 在「公众号成稿」中选择手机宽度，检查实际 HTML，再复制、导出或同步到草稿。

所有组件现在统一跟随当前主题配色、字体和字号，并使用直角边框。旧组件名称和内容属性保持可用；缩略图与正文采用同一适配规则。额外自定义 CSS 仍可覆盖预设，验收时应使用相同配置。

## 一致性实现

- 章节数字和装饰线是渲染管线生成的真实节点，不使用 CSS 计数器、伪元素或 3D 变换。
- 本地即时预览和成稿生成共用装饰函数。复制、HTML 导出和 COSE 正文继续使用统一的成稿产物。
- 字体、正文参数、代码高亮、引言和装饰均内联到 HTML。Mac 圆点不依赖原文的远程 SVG。
- 参考主题的独立成稿使用 20px 页面边距与 10px 正文内边距，对齐原文在 390px 屏幕下的主要内容宽度。

浏览器已核对本地与隔离成稿中的正文字体、14px 字号、22.4px 行高、34px 缩进、引言 24.5px 行高，以及代码 12px / 26px 的计算样式一致。成稿不依赖外部 CSS 或 SVG。

真实公众号草稿尚未在账号中验收。字体由阅读设备决定：未安装楷体或兼容字体时会回退；公众号也可能清洗样式、转存图片并适配深色模式。因此可保证本地交付 HTML 的一致性，不能在没有实际草稿和手机预览的情况下承诺所有设备的像素级相同。以图片导出的报表保留自身字体和配色，但正文保留可选择、可复制文本。
