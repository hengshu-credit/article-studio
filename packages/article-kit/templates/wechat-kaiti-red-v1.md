## 方法概览

数据分析首先需要明确观察对象、统计时间和样本范围。同一个指标在不同的分母口径下可能呈现不同含义，因此在展示结果之前，需要记录清晰的定义。

对于技术文章，正文用来解释方法，代码用来说明复现步骤。复杂的报表和宽表可以作为图片插入，避免在手机屏幕上压缩成难以阅读的文字。

## 样本与分布

### 样本检查

先记录样本总量、缺失情况和异常值规则，再开展特征分布比较。以下为演示数据，不包含真实业务记录。

#### 特征区分度

比较不同特征取值下的目标分布，并结合样本量与验证集表现判断差异是否稳定。

<WeChatHighlightV1>

用于比较的数据应当保持时间窗口和筛选条件一致。分箱边界应在训练样本上确定，再应用到其他样本。

</WeChatHighlightV1>

### 代码示例

```python
import pandas as pd

# 创建演示样本
sample = pd.DataFrame({
    "age": [22, 25, 29, 34, 38, 42, 51, 57],
    "event": [0, 0, 1, 0, 1, 0, 1, 1],
})

# 固定分箱边界后进行分组统计
sample["age_bin"] = pd.cut(
    sample["age"], bins=[18, 30, 45, 60]
)
summary = sample.groupby(
    "age_bin", observed=False
)["event"].agg(["count", "mean"])
print(summary)
```
